# headhunter-agent

[English](README.md) | **繁體中文**

**給 Claude Code 與其他 AI agent 使用的 AI 獵頭。** 可以用在自己的求職，也能同時替很多位候選人操作。建立候選人資料庫、讀取職缺網站、評估每個職缺與每位候選人的適合度、產出中英雙版客製履歷，並追蹤每一次投遞的進度與回饋。

> **狀態：** 開發中。開發藍圖與各功能規格都在 [roadmap epic](https://github.com/codeotter0201/headhunter-agent/issues/3) 追蹤。

## 為什麼需要它

求職過程累積的資料多到很難記清楚：舊履歷、筆記、工作紀錄、證照與 repo，看過的每個職缺、每次投遞的結果，以及下次要修正什麼。`headhunter-agent` 就是你的個人獵頭：你就是它的候選人，它會記住這一切，而且每一條事實都保留出處。獵頭和職涯顧問也能用同一套流程，同時替**很多位候選人**操作。

## 功能

- **候選人資料庫**：關於候選人的任何資料都能交給它：筆記、工作紀錄、照片、舊履歷、GitHub repo。它會檢查每份資料缺了哪些細節、哪些描述太模糊、和既有資料有沒有矛盾，提出追問，並用共用的中英標籤分類每一條事實。每一條事實都保留出處，沒有你確認不會自行補上內容。支援新增、查看、更新、封存，可依技能、產業、職級、工作年資、證據強度或狀態查詢候選人和事實。
- **角色檔案**：一位候選人可以同時鎖定好幾個角色，例如後端工程師和技術主管。每個角色會列出條件，把支持每條條件的事實連結起來並說明理由，同時指出缺口：沒有證據、只有未確認的推論，或只有自述的證據，每個缺口都附上補強方式。事實有變動時，會告訴你哪些角色檔案需要更新。可以依角色、要求的技能，或必備條件沒有缺口的角色來查詢候選人。
- **讀取職缺**：職缺可以用任何形式交給它：104、CakeResume、Yourator、企業官網或 LinkedIn 的列表或職缺網址、PDF 或 HTML 檔、截圖，或複製的文字，一個或一批都可以。它會先讀標題粗篩，再逐一讀取完整職缺內容並存成快照：必備條件、加分條件、工作內容、薪資與地點，條件會用和候選人事實相同的標籤分類。Yourator 和企業官網直接讀取，並遵守各網站的 robots.txt。104 和 CakeResume 會擋自動化請求，所以改由 skill 引導你：把搜尋結果捲到所有職缺都載入、複製整頁貼上，職缺頁則從你的瀏覽器讀取或用你複製的文字。LinkedIn 只讀你已登入瀏覽器中開啟的頁面或你貼上的文字。
- **職缺評估**：可針對一位候選人，或從整個資料庫找出角色符合職缺的候選人，並依符合的角色評估；沒有符合的角色時，改用候選人的全部事實評估，並提議從這個職缺建立新角色。每份評估依固定評分標準（技能重疊、職級、產業與領域、成就、薪資地點與工作模式）給出適合度分數，推薦原因會對應到具體的事實和職缺條件，列出缺口與風險及補強方式，並給出高／中／低的成功率等級與理由。不符合硬性條件（例如最低年資或指定學歷）時，等級降一級。同一角色下評估過的職缺若反覆出現同樣的條件，會提議加進該角色，經你同意才套用。
- **客製履歷**：每個評估過的投遞都產出中文與英文兩版，Markdown 與 PDF 格式。履歷從該職缺評估時所用角色的角色檔案出發，把最相關的事實放前面，只使用有出處的事實：每一行都註明出自哪些事實，數字必須和事實一致，候選人缺少的技能不會寫進去，公司、職稱和學校的英文名稱一律依照候選人的對照表。PDF 用 Chrome、Chromium 或 Edge 產生，文字可以正確複製，求職系統（ATS）也能正確讀取。
- **投遞進度追蹤**：每組「候選人 × 職缺」依階段推進（發現 → 已評估 → 準備中 → 已投遞 → 面試 → Offer → 結案），保留有日期的歷程，每輪面試分開記錄，進行中的投遞都有下一步與期限。可以列出所有候選人逾期的待辦，依候選人、角色、職缺或公司查看進度，結案時記錄結果：錄取、婉拒、未錄取或撤回。
- **回饋與修正**：記錄來自 HR、面試官、候選人與你自己的回饋、原因分類與具體修正方向，並追蹤每項修正直到完成；會產出新資料的修正（例如作品集）要匯入成資料來源才算完成。同一位候選人的多次投遞或同一角色下重複出現的原因，會變成對求職策略、角色檔案與履歷的修改提議，經你同意才套用。回饋中關於公司的內容會跨候選人累積成公司情報。結案的投遞會和成功率等級比對，指出評分高估或低估之處，要不要調整評分標準由你決定。

## 安裝

skill 的輔助腳本需要 Python 3.9 以上，不需安裝其他套件。匯入 GitHub repo 或個人頁面時會用到 [GitHub CLI](https://cli.github.com)（`gh`）。履歷轉成 PDF 時會用到 Google Chrome、Chromium 或 Microsoft Edge。

### Clone 後直接使用（任何 AI agent）

```bash
git clone https://github.com/codeotter0201/headhunter-agent.git
cd headhunter-agent
```

在這個資料夾啟動你的 AI agent，告訴它你想做什麼，例如「把我加為候選人，並匯入這份履歷」。在 Claude Code 也可以輸入 `/headhunter`。要更新時，在這個資料夾執行 `git pull`。

Agent 會在 `.claude/skills/` 或 `.agents/skills/` 找到 skill，不支援自動發現 skill 的 agent 則由 `AGENTS.md` 引導使用。Agent 必須能讀取檔案並執行指令，因此只能對話的 AI 服務無法執行這個 skill。這兩個 skill 資料夾是符號連結：在 Windows 上請先啟用符號連結再 clone，或使用會讀取 `AGENTS.md` 的 agent。

### Claude Code plugin

要在 Claude Code 的任何資料夾使用這個 skill：

```
/plugin marketplace add codeotter0201/headhunter-agent
/plugin install headhunter@headhunter-agent
```

安裝後在 Claude Code 輸入 `/headhunter:headhunter`。

### 在任何資料夾使用其他 AI agent

支援 Agent Skills 格式的 agent 可以在任何地方使用這個 skill：把 `skills/headhunter/` 複製到該 agent 的 skills 資料夾即可。

## 資料只存在本機

候選人資料永遠不會進入這個 repo，只存在你電腦上的 `~/headhunter-data/`（或 `HEADHUNTER_DATA_DIR` 指定的資料夾），也不會上傳到任何第三方服務。

## 參與開發
